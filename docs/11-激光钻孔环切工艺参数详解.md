# 11 - 激光钻孔环切工艺参数详解

## 一、概述

### 1.1 核心工艺短板

在激光钻孔范式中，"按孔径分组排序"被明确认定为**机械钻遗留假设**，属负优化（会导致振镜空程暴增）。但**环切工艺参数未按孔径分档**是真正的核心工艺短板🟠。

### 1.2 解决方案

实现**按孔径自动分档配置**环切工艺参数：
- 微孔（≤1mm）：低功率 + 少圈数 → 防过烧
- 中孔（1-3mm）：均衡参数
- 大孔（3-5mm）：高功率 + 多层螺旋
- 特大孔（>5mm）：超高功率 + 多层冷却循环

## 二、核心 API 设计

### 2.1 TrepanParams 类

**位置**：`src/GalvoStage.Core/Drilling/TrepanParams.cs`

```csharp
public sealed class TrepanParams
{
    /// <summary>激光功率 (W)，范围 0-15000</summary>
    public double Power { get; init; }

    /// <summary>补偿圈数（从中心向外扩展的扩孔层数）</summary>
    public int OffsetRings { get; init; }

    /// <summary>进给速度 (mm/s)</summary>
    public double FeedRate { get; init; }

    /// <summary>持留时间 (ms)，用于孔边缘熔化</summary>
    public double HoldTime { get; init; }

    /// <summary>冷却间隔 (ms)，大孔需要分层后暂停冷却</summary>
    public double CoolDownInterval { get; init; }

    /// <summary>脉冲占空比 (0.0-1.0)，1.0 为连续输出</summary>
    public double DutyCycle { get; init; }
}
```

### 2.2 预设策略

#### 小孔策略（≤1mm 微孔）
```csharp
public static readonly TrepanParams SmallHole = new()
{
    Power = 5000,           // 低功率防过烧
    OffsetRings = 1,        // 单层环切
    FeedRate = 80,          // 较慢进给
    HoldTime = 20,          // 短持留
    CoolDownInterval = 0,   // 无需冷却
    DutyCycle = 1.0         // 连续输出
};
```

**适用场景**：PCB 微孔、精密电子元件  
**物理意义**：避免热影响区过大，防止材料碳化

#### 中孔策略（1-3mm）


**适用场景**：标准 PCB 通孔  
**物理意义**：平衡效率与质量

## 三、自动分档逻辑

### 3.1 CreateForDiameter 方法

```csharp
public static TrepanParams CreateForDiameter(double diameter)
{
    if (diameter <= 1.0)          // ≤1mm 微孔
        return SmallHole;
    else if (diameter <= 3.0)     // 1-3mm 中孔
        return MediumHole;
    else if (diameter <= 5.0)     // 3-5mm 大孔
        return LargeHole;
    else                          // >5mm 特大孔
        return ExtraLargeHole;
}
```

### 3.2 集成到 Hole 结构

**位置**：`src/GalvoStage.Core/Geometry/Drilling/DrillingPattern.cs`

```csharp
public struct Hole
{
    public double X, Y;
    public double Diameter;
    public string Layer;
    public int OriginalIndex;
    
    /// <summary>工艺参数（按孔径分档配置）</summary>
    public TrepanParams ProcessParams { get; set; }
    
    /// <summary>根据孔径自动设置工艺参数</summary>
    public void RecomputeProcessParams()
    {
        if (Diameter > 0)
            ProcessParams = TrepanParams.CreateForDiameter(Diameter);
        else
            ProcessParams = TrepanParams.MediumHole; // 默认中孔参数
    }
}
```

## 四、集成流程

### 4.1 DecomposeBoth 调用链

**位置**：`src/GalvoStage.App/ViewModels/MainViewModel.cs`

```csharp
public void DecomposeBoth()
{
    bool hasPoly = Polylines.Count > 0;
    bool hasDrill = DrillingPattern != null && DrillingPattern.Holes.Count > 0;
    if (!hasPoly && !hasDrill) return;

    // ① 钻孔链路：先按孔径分档设置工艺参数（结构体需显式回写）
    if (hasDrill)
    {
        var holes = DrillingPattern.Holes;
        for (int i = 0; i < holes.Count; i++)
        {
            var h = holes[i];
            h.RecomputeProcessParams();
            holes[i] = h;
        }
        // ② 钻孔路径规划：振镜优先 + 采样速度 + 加工策略（工艺优先/时间最短）
        DrillingTrajectory = DrillPlanner.Plan(DrillingPattern, dwellTimeMs: 50.0,
            galvoFov: GalvoFov, galvoFirst: true,
            jumpSpeedPlatform: JumpSpeedPlatform, jumpSpeedGalvo: JumpSpeedGalvo,
            sampleRate: SampleRate,
            strategy: DrillQualityFirst ? DrillingStrategy.QualityOptimal
                                        : DrillingStrategy.TimeOptimal);
        // …环切动画帧生成略…
    }

    // 仅折线 → Decompose()；仅钻孔 → DecomposeDrilling()
    if (hasPoly && !hasDrill) { Decompose(); return; }
    if (!hasPoly && hasDrill) { DecomposeDrilling(); return; }

    // ③ 双模式：排除由 CIRCLE 细分而来的折线（FromCircle），避免圆被加工两次
    var contourPolys = Polylines.Where(p => !p.FromCircle).ToList();
    if (contourPolys.Count == 0) { DecomposeDrilling(); return; }

    // ④ 折线采样 + 钻孔采样，拼接成单条轨迹后只做一次频域分解
    var trajP = PathSampler.Sample(contourPolys, FeedSpeed,
        JumpSpeedPlatform, JumpSpeedGalvo, SampleRate,
        cornerAngleDeg: 150, accelPlatform: AccelPlatform,
        accelGalvo: AccelGalvo, cornerFactor: CornerFactor);
    Vec2? startFrom = trajP.Count > 0 ? new Vec2(trajP.X[^1], trajP.Y[^1]) : (Vec2?)null;
    var trajD = BuildDrillingSampledTrajectory(out _, out _, out _, out _, startFrom);
    var combined = ConcatTrajectories(trajP, trajD);   // 先轮廓，后圆孔

    Plan = AutoCutoff
        ? FrequencyDecomposer.DecomposeAuto(combined, GalvoFov)
        : FrequencyDecomposer.Decompose(combined, CutoffHz, GalvoFov);
    // …RebuildSimulator / PlanInfo 略…
}
```

**关键点**：
- 工艺参数在 `DecomposeBoth` 内**先** `RecomputeProcessParams`，**再** `DrillPlanner.Plan`（不是先 `Decompose()` 再补参数）。
- `strategy` 由 UI 的 `DrillQualityFirst` 决定：`QualityOptimal`（按孔径分组）或 `TimeOptimal`（默认）。
- 折线里 `FromCircle == true` 的部分被排除，圆孔统一交给钻孔链路环切，避免重复加工。
- 折线与钻孔各自采样后由 `ConcatTrajectories` 拼成**一条**轨迹，只做一次频域分解——先加工轮廓再加工圆孔，两模式共享同一 Plan/Sim。

### 4.2 参数传递到 HoleMove

**位置**：`src/GalvoStage.Core/Drilling/DrillPlanner.cs`

```csharp
public static DrillingTrajectory Plan(DrillingPattern pattern, ...)
{
    // 排序策略由 strategy 决定：QualityOptimal 按孔径分组，否则分区+TSP
    var ordered = strategy == DrillingStrategy.QualityOptimal
        ? OrderByDiameterGroups(pattern.Holes, galvoFov, galvoFirst)
        : OrderHoles(pattern.Holes, galvoFov, galvoFirst);
    
    var trajectory = new DrillingTrajectory();
    for (int i = 0; i < ordered.Count; i++)
    {
        var h = ordered[i];
        trajectory.Moves.Add(new HoleMove
        {
            Position = new Vec2(h.X, h.Y),
            Diameter = h.Diameter,
            ProcessParams = h.ProcessParams  // ← 传递工艺参数
        });
    }
    return trajectory;
}
```

## 五、G 代码导出

### 5.1 ExportLaserDrilling 方法

**位置**：`src/GalvoStage.Core/Drilling/GCodeExporter.cs`

```csharp
public static int ExportLaserDrilling(DrillingTrajectory trajectory, string path, ...)
{
    foreach (var m in moves)
    {
        var pp = m.ProcessParams ?? TrepanParams.MediumHole;
        
        // 设置激光功率和进给
        w.WriteLine($"M10 P{pp.Power}");
        w.WriteLine($"G1 F{pp.FeedRate}");
        
        // 环切加工：从中心向外扩展
        for (int ring = 0; ring < pp.OffsetRings; ring++)
        {
            double ringRadius = radius * (ring + 1) / pp.OffsetRings;
            // 生成圆周轨迹
            for (int seg = 0; seg <= segments; seg++)
            {
                double angle = 2 * Math.PI * seg / segments;
                double cx = m.Position.X + ringRadius * Math.Cos(angle);
                double cy = m.Position.Y + ringRadius * Math.Sin(angle);
                w.WriteLine($"X{cx:F4} Y{cy:F4}");
            }
            
            // 冷却间隔（大孔需要）
            if (pp.CoolDownInterval > 0 && ring < pp.OffsetRings - 1)
            {
                w.WriteLine($"G4 P{pp.CoolDownInterval} (cool down)");
            }
        }
        
        // 持留时间
        if (pp.HoldTime > 0)
        {
            w.WriteLine($"G4 P{pp.HoldTime} (hold)");
        }
        
        w.WriteLine("M10 P0");  // 关闭激光
    }
}
```

```csharp
private static void DrawDrillingPattern(SKCanvas canvas, ...)
{
    foreach (var h in holes)
    {
        // 功率梯度颜色映射
        SKColor holeColor = DrillPointColor;
        if (h.ProcessParams != null)
        {
            double power = h.ProcessParams.Power;
            if (power <= 5000) holeColor = SKColors.Cyan;         // 微孔：青色
            else if (power <= 8000) holeColor = SKColors.Lime;    // 小孔：绿色
            else if (power <= 12000) holeColor = SKColors.Yellow; // 中孔：黄色
            else if (power <= 15000) holeColor = SKColors.Orange; // 大孔：橙色
            else holeColor = SKColors.Red;                        // 特大孔：红色
        }
        
        // 绘制带颜色的孔轮廓
        paint.Color = holeColor;
        canvas.DrawCircle(center, radius, paint);
    }
}
```

## 九、最佳实践

### 9.1 参数调优建议

1. **微孔（≤1mm）**
   - 功率不宜过高（≤6000W）
   - 单层环切即可
   - 持留时间短（≤30ms）

2. **中孔（1-3mm）**
   - 标准参数即可
   - 可适当增加圈数提高质量

3. **大孔（>3mm）**
   - 必须多层螺旋
   - 层间冷却防止热积累
   - 脉冲模式优于连续

### 9.2 常见问题

**Q1：为什么不用按孔径分组排序？**  
A：激光钻孔无需换刀，按孔径分组会导致振镜空程暴增，属负优化。

**Q2：如何自定义分档策略？**  
A：修改 `TrepanParams.CreateForDiameter` 方法，或添加新的预设策略。

**Q3：如何验证参数是否合理？**  
A：使用 `TrepanBench` 工具对比不同策略的加工质量指标。
