## 1. 背景与目标

### 1.1 问题背景

大幅面激光加工中存在一对固有矛盾：

| 执行器 | 优势 | 劣势 |
|--------|------|------|
| **振镜（Galvo）** | 响应快（亚毫秒级）、精度高 | 视场小（通常 ±5~±50 mm），无法覆盖大幅面 |
| **XY 平台（Stage）** | 行程大（可达米级） | 惯量大、带宽低（十几 Hz），跟随高频轮廓时误差大 |

单独使用任一执行器都无法在**大幅面**下同时满足**高精度**与**高速度**。

### 1.2 联动方案思路

**振镜 + 平台联动（Galvo-on-Stage）** 将两者叠加：

```
激光落点位置 = 平台实际位置 + 振镜偏摆量
```

- **平台**承担轨迹的**低频大行程**分量（缓慢、平滑地移动，覆盖整个幅面）；
- **振镜**承担轨迹的**高频小行程**分量（快速跟随细节），并**实时补偿平台的跟随误差**。

由此在理论上实现"**大幅面 + 高速度 + 高精度**"三者兼得。

### 1.3 预研目标

本原型验证以下四个核心技术点（对应需求）：

1. ✅ 技术栈：**WPF + .NET 6.0 + SkiaSharp**
2. ✅ 支持**导入 DXF 实时加工图形**
3. ✅ 基于**频率算法**对加工图形进行**路径分解**（振镜路径 + 平台路径）
4. ✅ **实时监控平台运动位置，计算误差，方向补偿到振镜**

## 4. 核心模块详解

### 4.1 DXF 解析（`DxfParser`）

轻量级 ASCII DXF 解析器，读取 `ENTITIES` 段并将各类实体**统一细分为折线**（`PathPolyline`），便于后续统一处理。

**支持的实体类型：**

| 实体 | 处理方式 |
|------|----------|
| `LINE` | 两点直线 |
| `CIRCLE` | 按弦高误差自适应细分为多边形 |
| `ARC` | 起止角圆弧细分（DXF 约定逆时针） |
| `LWPOLYLINE` | 轻量多段线，支持**凸度 bulge**（圆弧段） |
| `POLYLINE` / `VERTEX` | 旧式多段线序列 |
| `ELLIPSE` | 椭圆/椭圆弧参数化采样 |
| `SPLINE` | NURBS 曲线（De Boor 算法采样）/ 拟合点回退 |

**自适应弦高细分**：圆弧按弦高误差 `ChordTolerance = 0.01 mm` 决定分段数，兼顾精度与点数：

```
maxStep = 2·arccos(1 − tol/r)      // 单段最大角步长
n = ⌈|sweep| / maxStep⌉            // 分段数，限幅 [4, 720]
```

### 4.2 路径采样（`PathSampler`）

将折线集合转换为**等时间间隔**（`dt = 1/采样率`）的采样轨迹 `SampledTrajectory`，这是联动控制的指令基准。

**关键处理：**

1. **贪心最近邻排序**：减少轮廓间空程（可整体反向折线），降低无效行程；
2. **空程/轮廓区分**：空程按**快移速度**插补（激光关），轮廓按**进给速度**插补（激光开）；
3. **跨段相位连续**：段间保持采样步距相位连续，避免接缝处采样密度突变。

输出：`X[]`、`Y[]`、`LaserOn[]` 三个等长数组 + 采样率。

### 4.3 频率分解（`FrequencyDecomposer`）★ 核心算法

**原理**：对等时采样轨迹做**零相位低通滤波**，把轨迹拆成两个频段：

```
原始轨迹 traj = 低频分量 stage + 高频残差 galvo
             │
             ├── stage = LowPass(traj)      → 平台指令（低频、大行程、平滑）
             └── galvo = traj − stage       → 振镜指令（高频、小行程、快速）
```

**低通滤波器实现**：二阶 Butterworth + **前向-反向双向滤波（filtfilt）**，实现**零相位**（无时间延迟），这对加工轨迹精度至关重要——普通滤波会引入相位滞后导致轨迹变形。

**截止频率自动搜索**（`DecomposeAuto`）：
- 截止频率越低 → 平台越平滑（加速度需求小），但振镜残差越大；
- 通过**二分查找**，找到使"振镜最大偏摆 ≤ 视场 × 安全裕度"成立的**最低截止频率**；
- 从而在**振镜不超视场**的前提下，**最小化平台的速度/加速度需求**。

**输出指标**：截止频率、振镜最大偏摆、平台峰值速度/加速度，用于评估方案可行性。

> 算法数学推导详见 [算法详解文档](./算法详解.md)。

### 4.4 动力学模型（`AxisModels`）

为在无硬件条件下验证联动逻辑，建立执行器仿真模型：

**平台单轴模型**（`StageAxisModel`）—— 二阶欠阻尼伺服系统：

```
x'' = ωn²·(u − x) − 2ζωn·x'          （ωn = 2π·带宽, ζ = 阻尼比）
```
叠加**正弦扰动**（模拟丝杠周期误差/导轨振动）与**随机噪声**，并带速度限幅。这样平台实际位置会**滞后并偏离**指令，产生真实的跟随误差。

**振镜单轴模型**（`GalvoAxisModel`）—— 一阶惯性环节：

```
pos += (clamp(u, ±FOV) − pos)·(1 − e^(−dt/τ))    （τ 亚毫秒级）
```
带视场限幅，响应远快于平台。

### 4.5 联动控制 + 误差补偿（`LinkageSimulator`）★ 核心逻辑

模拟 kHz 级实时控制环，每个控制周期执行：

```
1. 下发平台低频指令（含前瞻前馈，补偿伺服固有滞后 ≈ 2ζ/ωn）
2. 读取平台编码器实际位置 act（含滞后/扰动）
3. 计算平台跟随误差   e = 指令 − 实测            ← 【实时监控 + 误差计算】
4. 振镜指令 = 高频分量 + e（方向补偿）          ← 【误差方向补偿到振镜】
5. 激光落点 = 平台实际位置 + 振镜实际偏摆
6. 落点误差 = |落点 − 理想轨迹|                 ← 精度评估
```

**误差补偿的本质**：平台跟不上指令产生的误差 `e`，由响应极快的振镜**反向叠加**补掉。这正是需求第 4 点"实时监控平台位置、计算误差、方向补偿到振镜"的实现。

**统计指标**：加工段（激光开）的最大落点误差、RMS 误差，用于量化补偿效果。

## 5. 界面功能

WPF 界面采用 MVVM 架构，深色工业风：

### 5.1 布局

- **顶部**：标题栏（渐变色 + 技术栈标签）
- **左侧参数面板**（卡片式分区）：
  1. 图形导入（导入 DXF / 加载示例）
  2. 频率分解（进给速度、采样率、振镜视场、截止频率）
  3. 联动仿真（平台带宽、扰动幅值、振镜时间常数、仿真倍速、**误差补偿开关**）
  4. 实时状态（进度、平台指令/实测、跟随误差、振镜偏摆、落点误差、统计）
- **右侧主画布**（SkiaSharp）：实时渲染
- **右下误差曲线**（SkiaSharp）：平台跟随误差 vs 补偿后落点误差

### 5.2 主画布图元

| 颜色 | 含义 |
|------|------|
| 灰色 | 原始 DXF 图形 |
| 蓝色 | 平台指令路径（低频分量） |
| 淡青 | 平台实际轨迹 |
| 红色 | 激光落点轨迹（出光段） |
| 绿色虚框 | 振镜视场（随平台移动） |
| 黄色 | 振镜偏摆矢量（平台位置 → 落点） |

**视图交互**：滚轮缩放、左键拖拽平移、双击自适应。

### 5.3 实时渲染机制

基于 `CompositionTarget.Rendering` 帧循环，按真实流逝时间推进仿真（支持倍速），驱动 SkiaSharp 重绘，实现流畅的实时加工动画。

## 6. 验证结果

内置示例图形 `demo.dxf`（9 个轮廓、总长 610 mm，含圆、圆弧、凸度多段线、星形、锯齿等）实测：

```
[DXF] 轮廓数=9  总长=610.2 mm
[采样] 点数=7975  时长=7.98 s
[分解] 截止频率=6.24 Hz  振镜最大偏摆=3.985 mm (视场±5)
[分解] 平台峰值速度=256.0 mm/s  峰值加速度=5029 mm/s²
[仿真] 补偿=关  最大落点误差=632.1 µm  RMS=147.5 µm
[仿真] 补偿=开  最大落点误差= 26.4 µm  RMS=  1.4 µm
```

**结论**：启用误差补偿后，加工段 **RMS 误差从 147.5 µm 降至 1.4 µm**（约 **100 倍**改善），最大误差从 632 µm 降至 26 µm。充分验证了"平台误差方向补偿到振镜"方案的有效性。

## 8. 局限与后续方向

本原型为**方案预研**，聚焦算法与联动逻辑验证，以下为后续工程化方向：

| 方向 | 说明 |
|------|------|
| 真实硬件对接 | 接入振镜控制卡（如 SCANLAB RTC）与平台运动控制器，替换仿真模型 |
| 位置反馈闭环 | 用真实编码器/光栅尺反馈替代扰动模型，验证实时性 |
| 前瞻算法增强 | 平台前瞻可升级为基于模型预测控制（MPC）的最优前馈 |
| DXF 兼容性 | 支持二进制 DXF、块引用（INSERT/BLOCK）、图层过滤 |
| 加工工艺 | 引入功率/频率/延时等激光工艺参数，跳转延时（jump delay）建模 |
| 分解算法 | 可探索基于加加速度（jerk）约束或频域最优分配的分解策略 |
