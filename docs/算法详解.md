# 算法详解

> 本文档详细阐述频率分解路径规划、零相位滤波、动力学模型与误差补偿的数学原理与实现细节。
> 概览请参见 [方案介绍](./方案介绍.md)。

## 1. 频率分解路径规划

### 1.1 核心思想

激光加工轨迹 $p(t) = (x(t), y(t))$ 在等时采样后，视为随时间变化的信号。将其在频域上分解：

$$
p(t) = \underbrace{p_{\text{stage}}(t)}_{\text{低频分量}} + \underbrace{p_{\text{galvo}}(t)}_{\text{高频分量}}
$$

- $p_{\text{stage}}(t) = \text{LowPass}(p(t))$ —— 交给 XY 平台执行（大行程、低带宽）；
- $p_{\text{galvo}}(t) = p(t) - p_{\text{stage}}(t)$ —— 交给振镜执行（小视场、高带宽）。

由于两执行器在物理上**位置叠加**：

$$
p_{\text{spot}}(t) = p_{\text{stage,actual}}(t) + p_{\text{galvo}}(t)
$$

若两者都能精确执行各自分量，则 $p_{\text{spot}}(t) = p(t)$，即完美复现原始轨迹。

### 1.2 为什么按频率分解？

执行器的能力本质是**带宽**约束：

- 平台带宽低（~10 Hz），只能跟随轨迹中变化缓慢（低频）的成分；
- 振镜带宽高（~kHz），可跟随快速变化（高频）的成分，但行程受视场限制。

频率分解恰好将信号按"变化快慢"分配给"响应快慢"匹配的执行器，是**能力与需求的最优匹配**。

### 1.3 截止频率的权衡

截止频率 $f_c$ 是关键参数，存在权衡：

| $f_c$ | 平台分量 | 振镜残差 | 影响 |
|-------|----------|----------|------|
| **偏低** | 更平滑，加速度小 | 偏大 | 可能超出振镜视场 |
| **偏高** | 更陡峭，加速度大 | 偏小 | 可能超出平台动力学能力 |

**振镜偏摆约束**：残差幅值必须落在视场内：

$$
\max_t \|p_{\text{galvo}}(t)\|_\infty \le \text{FOV}
$$

**平台动力学约束**：低频分量的速度、加速度必须在平台能力内：

$$
\max_t \|\dot{p}_{\text{stage}}\| \le v_{\max}, \quad \max_t \|\ddot{p}_{\text{stage}}\| \le a_{\max}
$$

## 2. 零相位低通滤波（filtfilt）

### 2.1 二阶 Butterworth 低通

采用双线性变换设计数字二阶 Butterworth 低通滤波器。记 $c = \cot(\pi f_c / f_s)$，$f_s$ 为采样率，则差分方程系数为：

$$
d = 1 + \sqrt{2}\,c + c^2
$$

$$
b_0 = \frac{1}{d}, \quad b_1 = \frac{2}{d}, \quad b_2 = \frac{1}{d}
$$

$$
a_1 = \frac{2(1 - c^2)}{d}, \quad a_2 = \frac{1 - \sqrt{2}\,c + c^2}{d}
$$

差分方程（直接 I 型）：

$$
y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2] - a_1 y[n-1] - a_2 y[n-2]
$$

对应代码 `FrequencyDecomposer.ButterLp2` 与 `Filter`。

### 2.2 为什么必须零相位？

普通 IIR 滤波会引入**相位滞后**：滤波后信号在时间上被延后。对加工轨迹而言，这意味着平台分量在时间上滞后于原始轨迹，会导致：

- 分解出的平台路径与原图形**形状偏移**（拐角滞后、圆变成蜗形）；
- 振镜残差不再是纯粹的"高频细节"，而混入了低频误差。

**解决方案：前向-反向双向滤波（filtfilt）**

$$
y_{\text{final}} = \text{Reverse}\Big(\text{Filter}\big(\text{Reverse}(\text{Filter}(x))\big)\Big)
$$

正向滤波产生的相位滞后，被反向滤波**精确抵消**，最终实现**零相位**。代价是幅频响应变为原来的平方（等效 4 阶），但相位为零——这对轨迹精度是必要的取舍。

### 2.3 边界处理

滤波在信号两端存在瞬态。采用**常值延拓**填充边界（长度取约 2 个截止周期 $2 f_s / f_c$），并将滤波器状态**稳态初始化**（$y_{-1} = y_{-2} = x_0$），避免起始/结束段出现虚假的大残差。

### 2.4 截止频率二分搜索

`DecomposeAuto` 求满足视场约束的最低截止频率：

```
limit = FOV × margin              // margin=0.8 安全裕度
若 f_c=上限 仍超视场 → 返回上限最优解（此图形无法完全联动）
若 f_c=下限 已满足   → 返回下限（平台最省力）
否则二分：
  mid = (lo + hi)/2
  分解并计算 maxDev
  maxDev ≤ limit ? hi = mid（可继续降低）: lo = mid（需提高）
```

由于"截止频率 → 振镜偏摆"是单调关系，二分收敛可靠（约 18 次迭代）。

## 3. 动力学模型

### 3.1 平台二阶欠阻尼系统

平台伺服系统建模为二阶系统，连续域微分方程：

$$
\ddot{x} = \omega_n^2 (u - x) - 2\zeta\omega_n \dot{x}
$$

其中 $\omega_n = 2\pi f_{\text{bw}}$（自然频率，$f_{\text{bw}}$ 为伺服带宽），$\zeta$ 为阻尼比，$u$ 为指令位置。

**数值积分**：采用显式欧拉法，并**细分子步**保证稳定性：

$$
\text{sub} = \lceil 4\, \omega_n\, dt \rceil, \quad h = dt / \text{sub}
$$

$$
\dot{x} \mathrel{+}= h\big[\omega_n^2(u-x) - 2\zeta\omega_n \dot{x}\big], \quad x \mathrel{+}= h\,\dot{x}
$$

**扰动叠加**：编码器实测位置 = 系统状态 + 正弦扰动 + 白噪声：

$$
x_{\text{meas}} = x + A_d \sin(2\pi f_d t + \phi) + \eta
$$

模拟丝杠周期误差（正弦项）与测量/机械噪声（$\eta$）。

### 3.2 振镜一阶惯性系统

振镜响应快，建模为一阶惯性环节：

$$
\text{pos}[n] = \text{pos}[n-1] + \big(\text{clamp}(u, \pm\text{FOV}) - \text{pos}[n-1]\big)\cdot\alpha
$$

$$
\alpha = 1 - e^{-dt/\tau}
$$

时间常数 $\tau$ 亚毫秒级（默认 0.3 ms），远小于平台响应时间，故振镜可近似"瞬时"跟随指令并补偿平台误差。

## 4. 误差补偿控制

### 4.1 控制环流程

每个控制周期（$dt = 1/f_s$）：

```
（1）平台指令前瞻前馈
     lead = i + LeadSamples
     actX = StagePlant(stageX[lead])     // 提前下发指令补偿伺服滞后
（2）读取平台实测位置 actX, actY（含扰动）
（3）计算跟随误差
     eX = stageX[i] − actX
     eY = stageY[i] − actY
（4）振镜指令 = 高频分量 + 误差补偿
     gCmdX = galvoX[i] + eX              // 补偿开启时
     gCmdY = galvoY[i] + eY
     gX = GalvoPlant(gCmdX)
（5）激光落点
     spotX = actX + gX
     spotY = actY + gY
（6）落点误差
     err = ‖(spotX, spotY) − (rawX[i], rawY[i])‖
```

### 4.2 前瞻前馈（Lead Feedforward）

平台二阶系统存在固有等效延迟，近似为：

$$
t_{\text{lag}} \approx \frac{2\zeta}{\omega_n}
$$

将其换算为采样数 $\text{LeadSamples} = \text{round}(t_{\text{lag}}/dt)$，**提前**下发平台指令。这样平台的实际响应在时间上与理想轨迹对齐，大幅减小系统性滞后误差（区别于随机扰动误差）。

### 4.3 补偿原理

设理想轨迹为 $p$，平台实测为 $p_s$，振镜偏摆为 $g$：

- **不补偿**时，振镜只执行预分解的高频分量 $g_0 = p_{\text{galvo}}$，落点 $= p_s + g_0$。由于 $p_s \ne p_{\text{stage}}$（有跟随误差 $e = p_{\text{stage}} - p_s$），落点偏离 $p$ 达 $e$。

- **补偿**时，振镜指令为 $g_0 + e$，落点：

$$
p_{\text{spot}} = p_s + (g_0 + e) = p_s + g_0 + (p_{\text{stage}} - p_s) = p_{\text{stage}} + g_0 = p
$$

即在振镜能精确执行的理想情形下，落点**精确回到理想轨迹**。实际因振镜自身有 $\tau$ 延迟和视场限幅，残余极小误差（实测 RMS ~1.4 µm）。

### 4.4 补偿有效性验证

内置示例的对比数据：

| 指标 | 补偿关闭 | 补偿开启 | 改善 |
|------|----------|----------|------|
| 最大落点误差 | 632.1 µm | 26.4 µm | ~24× |
| RMS 落点误差 | 147.5 µm | 1.4 µm | ~105× |

**关键洞察**：平台的低频跟随误差与扰动，几乎全部被高带宽振镜实时"吸收"，这正是振镜-平台联动方案的核心价值。

## 5. 复杂度与性能

| 环节 | 复杂度 | 说明 |
|------|--------|------|
| DXF 解析 | $O(N_{\text{codes}})$ | 单遍扫描组码 |
| 路径采样 | $O(N_{\text{seg}} + M)$ | $M$ 为采样点数；排序为 $O(K^2)$，$K$ 为轮廓数 |
| 频率分解 | $O(M)$ | filtfilt 线性；自动搜索约 18× |
| 联动仿真 | $O(M \cdot \text{sub})$ | 每点固定子步积分 |
| 渲染 | $O(M / \text{stride})$ | 长路径降采样绘制，避免卡顿 |

实测 8000 采样点全链路（解析→分解→整段仿真）在毫秒~百毫秒级完成，界面实时仿真流畅。
