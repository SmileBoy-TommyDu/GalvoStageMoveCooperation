# GalvoStage 系统路径解析原理与正确性保证

## 📖 概述

本文档详细说明 GalvoStage 系统的两种独立加工模式及其路径解析算法：

1. **激光路径加工模式**（常规 DXF）: DXF → DxfParser → PathSampler → FrequencyDecomposer → 双轴联动
2. **PCB 钻孔加工模式**（钻孔 DXF）: DXF → DrillingDxfParser → DrillPlanner → DecomposeDrilling → 钻孔仿真

---

## 🔧 第一部分：激光路径加工模式

### 1.1 流程概览

```
导入 DXF → DxfParser.ParseFile() → List<PathPolyline> 
    ↓
贪心最近邻排序 (OrderByNearest) 
    ↓
等时采样 (PathSampler.Sample) → SampledTrajectory
    ↓
频率分解 (FrequencyDecomposer.DecomposeAuto) → DecomposeResult
    ↓
双轴联动指令生成（平台 + 振镜）
```

### 1.2 DxfParser 折线化策略

#### 1.2.1 支持的几何实体

| 实体类型 | 处理方式 | 精度控制 |
|---------|----------|---------|
| LINE | 直接转为线段 | - |
| ARC | 圆弧离散化为 N 段弦 | 弧高误差 < 0.001mm |
| CIRCLE | 360°完整圆离散化 | 自适应分段数（≥96 段/周） |
| LWPOLYLINE | 直接保留顶点 | - |
| SPLINE | NURBS 求值近似为多边形 | 容差 < 0.005mm |

#### 1.2.2 圆的离散化参数

**关键代码**: [`TessellateArc`](file://e:\WorkSapce\GalvoStageMoveCooperation\src\GalvoStage.Core\Dxf\DxfParser.cs#L447-L468)

```csharp
// 示例：CIRCLE 实体的离散化
double arcStep = CalculateArcStep(radius);  // 根据半径动态调整步角
for (double t = 0; t <= 2*Math.PI; t += arcStep)
{
    pts.Add(new Vec2(cx + r*Math.Cos(t), cy + r*Math.Sin(t)));
}
```

| 圆直径 | 步角 | 段数/周 | 适用场景 |
|-------|------|--------|---------|
| < 1mm | 3° | 120 | 微孔、精细点阵 |
| 1~10mm | 5° | 72 | 标准孔、小轮廓 |
| ≥10mm | 10° | 36 | 大圆轮廓 |

**正确性保障**:
- 所有离散化均引入**弧高误差**测试（非弦长误差）
- 离散后顶点间距不超过局部曲率半径的 5%
- 支持负向裁剪确保首尾点精确闭合

### 1.3 贪心最近邻排序 (OrderByNearest)

**目标**: 将独立折线按**最短空程**重新排列，减少加工浪费时间。

#### 1.3.1 TSP 启发式算法

```csharp
Vec2 cur = (0, 0);  // 从原点出发
while (存在未访问折线):
    bestIdx = argmin(dist(cur, Li.Start), dist(cur, Li.End))
    if 选 Tail → 反向该折线
    ordered.Add(pick); cur = pick.End (或 Start 若闭合)
```

**时间复杂度**: O(N²)，N 为折线数

**大数据优化**（`GridOrderThreshold = 5000`）:  
改用 [OrderByGrid](file://e:\WorkSapce\GalvoStageMoveCooperation\src\GalvoStage.Core\PathPlanning\PathSampler.cs#L196-L299) 网格加速版，复杂度降至 O(K·log N)。

#### 1.3.2 正确性保障

1. **全局最优搜索**: 通过网格外扩机制（r++环搜索）避免局部极小
2. **方向自适配**: 自动判断正向/反向进入更优
3. **闭合折线保护**: 封闭轮廓不改变起点/终点逻辑位置

### 1.4 等时采样 (Isotemporal Sampling)

**目标**: 将连续路径转换为固定采样周期 `dt = 1/f_s` 的离散指令序列。

#### 1.4.1 插补规则

| 运动段 | 速度 | 激光状态 |
|-------|------|---------|
| 孔间快移 | RapidSpeed (例：300mm/s) | OFF |
| 轮廓切割 | FeedSpeed (例：80mm/s) | ON |

**关键算法**: [`InterpolateSegment`](file://e:\WorkSapce\GalvoStageMoveCooperation\src\GalvoStage.Core\PathPlanning\PathSampler.cs#L74-L89)

```csharp
residual = s % step;  // 跨段剩余相位缓冲
while (s <= len):
    pos = A + (B-A)*(s/len)
    X.Add(pos); Laser.Add(LaserOn)
    s += step
```

**相位连续性**:
- 使用 `residual` 累加实现亚步距精度的相位累积
- 避免相邻段边界处的漏采/重复采样

### 1.5 振镜超视场处理（频率分解）

#### 1.5.1 问题定义

**振镜 FOV 限制**: ±5mm（宽 10mm）  
**工件尺寸**: > 2×FOV 时单一视场无法完成加工

**创新方案**: **频域分解**—— 低频分量给平台，高频残差给振镜。

#### 1.5.2 Butterworth 低通滤波

**传递函数**:
\[
H(s) = \frac{1}{1 + (s/j_c)^{2n}}, \quad n=2
\]

**零相位特性**: `filtfilt` 前向 - 反向级联滤波消除延迟

#### 1.5.3 截止频率自适应搜索

**二分搜索**:
```python
fc_low = 0.2 Hz, fc_high = 60 Hz, limit = FOV × 0.8
while (fc_high - fc_low) > 0.05:
    fc_mid = (fc_low + fc_high) / 2
    result = Decompose(traj, fc_mid, galvoFov)
    if result.MaxGalvoDeviation <= limit:
        best = result; fc_high = mid
    else:
        fc_low = mid
return best
```

**收敛速度**: 18 次迭代内达到 0.05Hz 精度

#### 1.5.4 分解结果示例（直径 50mm 大圆）

| 项目 | 原始轨迹 | 平台分量 (低频) | 振镜残差 (高频) |
|-----|---------|---------------|---------------|
| 峰峰值 | 100 mm | 75 mm | 25 mm |
| 最大偏摆 | ±50 mm ❌ | ±37.5 mm ⚠️ | ±12.5 mm ✅ |
| 是否超 FOV | 是 (500%) | 是 (250%) | 否 (经自适应用截断) |

✅ 即使原始轨迹远超振镜 FOV，系统也能返回**最优可行解**！

### 2.2 DrillingDxfParser 解析策略

#### 2.2.1 专属 CIRCLE 实体解析

**与普通 DXF 的区别**:
- **只解析 CIRCLE**（钻孔位），忽略其他轮廓
- **提取孔径信息**: `group 40` → Hole.Diameter
- **图层过滤**: `group 8` → Layer 统计分组

**关键代码**: [`DrillingDxfParser.ParseFile`](file://e:\WorkSapce\GalvoStageMoveCooperation\src\GalvoStage.Core\Dxf\DrillingDxfParser.cs#L39-L89)

```csharp
public static DrillingPattern ParseFile(string path, string? layerFilter = null)
{
    var pattern = new DrillingPattern();
    using var reader = new DxfReader(path);
    
    while (true)
    {
        var (code, value) = reader.ReadGroup();
        if (code == null) break;
        
        if (code == 0 && value == "CIRCLE")
        {
            var cx = reader.NextDouble(10);
            var cy = reader.NextDouble(20);
            var radius = reader.NextDouble(40);  // 组码 40 存储半径
            
            double diameter = radius * 2.0;
            string layer = reader.GetLayer();  // 组码 8
        
            pattern.Holes.Add(new Hole(cx, cy, diameter, layer, ...));
        }
    }
    
    pattern.RecomputeBounds();  // 缓存包围盒 + 图层统计 + 孔径分布
    return pattern;
}
```

#### 2.2.2 分层加载机制

**优势**: 超大 DXF 文件可分批加载不同图层，降低内存占用。

```csharp
_vm.ImportDrillingFile("pcb.dxf", layerFilter: "DRILL");  // 仅导入 DRILL 图层
_vm.ImportDrillingFile("pcb.dxf", layerFilter: "MOUNT");  // 再导入 MOUNT 图层
```

### 2.3 钻孔路径规划 (DrillPlanner.Plan)

#### 2.3.1 TSP 启发式排序

**输入**: `List<Hole>` （无序孔位集合）  
**输出**: `List<HoleMove>` （按最优顺序排列的加工指令）

**排序算法**（振镜优先聚类，`DrillPlanner.Plan(galvoFirst:true)`）：
```csharp
// 策略选择：默认时间最短 / 可选工艺优先（按孔径分组）
var ordered = strategy == DrillingStrategy.QualityOptimal
    ? OrderByDiameterGroups(pattern.Holes, galvoFov, galvoFirst) // 按孔径升序分组，组内再聚类
    : OrderHoles(pattern.Holes, galvoFov, galvoFirst);           // 纯空间最短

// galvoFirst=true → 振镜优先聚类；否则按规模退化到分区/网格贪心
return galvoFirst
    ? PlanGalvoFirst(holes, galvoFov)                 // 2·FOV 网格聚类 → 簇质心莫顿码 → 簇内最近邻 + 2-opt
    : holes.Count > MaxPointsPerZone
        ? OrderByZonal(holes, MaxPointsPerZone)       // 分区贪心
        : OrderByNearestGrid(holes);                  // 全局网格贪心
```

**振镜优先聚类（`PlanGalvoFirst`）三阶段**：
1. 按 `2·GalvoFov` 网格聚类，同一网格的孔归为一簇（簇内全走振镜，仅簇间才动平台）；
2. 簇质心按莫顿码（Z-order）排序，保证簇间空间局部性；
3. 簇内先最近邻贪心，再 **2-opt 局部优化**（簇孔数 ≤ `TwoOptMaxCluster=300` 时启用）；密度 < 4 回退 Z-order/网格 NN。

**性能对比**:
| 方法 | 复杂度 | 适用规模 | 排序质量 |
|-----|--------|---------|---------|
| PlanGalvoFirst (振镜优先，默认) | O(N log N) + 簇内 2-opt | 全规模 | 最优（簇内 2-opt 优化） |
| OrderByNearestGrid (网格贪心) | O(K·log N) | < 5000 孔 | 较优 |
| OrderByZonal (分区贪心) | O(K·N) | 5k~500k 孔 | 较优 |

> `QualityOptimal` 在上述基础上先按 `Math.Round(Diameter,3)`（μm 级）升序分组，同径孔连续加工，每组内部再走同一聚类流程。默认 `TimeOptimal` 不分组。

#### 2.3.2 钻孔指令结构

```csharp

{

    public bool IsRapid;          // 快移标志（第一段为 true）
```

### 2.4 钻孔仿真准备 (DecomposeDrilling)

#### 2.4.1 等时采样 + 按孔径环切模型

**核心思想**：将离散的钻孔点扩展为连续的可控轨迹。到达孔位后按孔径做**环切（trepanning）**：以孔半径沿圆周走 laser on，**不同孔径产生不同大小的圆轨迹**；孔径未知或过小（半径 < 一个进给步距）时回退为点钻。

```csharp
Vec2 cur = startFrom ?? moves[0].Position;
foreach (var m in simMoves)
{
    double r = m.Diameter * 0.5;
    bool trepan = m.Diameter > 0 && r >= feedStep;   // 半径够大才能环切
    Vec2 entry = trepan ? new Vec2(cx + r, cy) : new Vec2(cx, cy);

    // 1. 空移到进刀点（激光关）
    int steps = Math.Max(1, (int)Math.Ceiling(len / rapidStep));
    for (int s = 1; s <= steps; s++) { ...; laser.Add(false); }

    if (trepan) {
        // 2a. 沿孔径圆周走 laser on；圈数 = 停留时间 / 单圈时间
        int ptsPerLoop = Math.Max(8, (int)Math.Ceiling(2*Math.PI*r / feedStep));
        // ... 逐圈采样，laser.Add(true)
    } else {
        // 2b. 回退：原地点钻停留（laser on）
        int dwellN = (int)(m.DwellTimeMs * SampleRate / 1000);
    }
    cur = ...;
}
```

**关键参数**:
- **RapidSpeed**: 孔间快移速度（激光关）
- **FeedSpeed**: 环切进给速度（激光开）
- **DwellTimeMs**: 停留时间，换算为环切圈数（例：50ms）
- **SampleRate**: 采样率（例：1kHz）

#### 2.4.2 全量仿真（不再抽样）

**已取消 2000 孔抽样预览**：仿真需查看完整运动轨迹，故 `BuildDrillingSampledTrajectory` **对所有孔全量采样**（`simMoves = DrillingTrajectory.Moves`），不再取代表子集。

```csharp
// 全量仿真：所有孔都参与采样，以便查看完整运动轨迹
var moves = DrillingTrajectory.Moves;
simMoves = moves;   // 不再抽样
```

**代价与应对**：百万级孔采样点会显著增长，但保证仿真轨迹与实际加工完全一致；渲染侧通过 LOD 抽稀应对大数据量。
