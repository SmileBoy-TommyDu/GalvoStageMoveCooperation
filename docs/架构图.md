## 1. 系统分层架构

```mermaid
flowchart TB
    subgraph App["GalvoStage.App （WPF 表现层）"]
        direction TB
        XAML["MainWindow.xaml<br/>深色工业风 UI / 卡片式参数面板"]
        VM["MainViewModel<br/>MVVM 状态管理 / 流水线编排"]
        Render["SceneRenderer<br/>SkiaSharp 实时渲染"]
        VT["ViewTransform<br/>世界↔屏幕坐标变换"]
    end

    subgraph Core["GalvoStage.Core （核心算法层 · 无 UI 依赖）"]
        direction TB
        Dxf["DxfParser<br/>DXF 解析（折线 + 双模式分离）"]
        Geo["Vec2 / PathPolyline<br/>几何基元"]
        Sampler["PathSampler<br/>等时采样 + 空程排序"]
        Freq["FrequencyDecomposer<br/>频率分解（核心算法）"]
        Drill["DrillPlanner / TrepanParams<br/>钻孔路径规划 + 环切工艺"]
        Sim["LinkageSimulator<br/>联动控制 + 误差补偿"]
        Axis["StageAxisModel / GalvoAxisModel<br/>动力学模型"]
    end

    subgraph Test["tools/SmokeTest （验证层）"]
        Smoke["命令行冒烟测试<br/>验证算法链路"]
    end

    XAML --> VM
    VM --> Render
    Render --> VT
    VM --> Dxf
    VM --> Sampler
    VM --> Freq
    VM --> Drill
    VM --> Sim
    Dxf --> Geo
    Sampler --> Geo
    Drill --> Geo
    Sim --> Axis
    Sim --> Freq
    Smoke --> Core

    style App fill:#1B2A4A,stroke:#4C8DFF,color:#E4E4EC
    style Core fill:#1C2E22,stroke:#2ECC71,color:#E4E4EC
    style Test fill:#2E2418,stroke:#E6A02E,color:#E4E4EC
```

**分层原则**：核心算法层（Core）完全独立于 UI，可单独编译、测试与复用；表现层（App）仅负责参数输入、状态编排与可视化；验证层（SmokeTest）绕过 UI 直接驱动算法链路，便于回归测试。

## 4. 联动控制时序（单个控制周期）

```mermaid
sequenceDiagram
    autonumber
    participant P as 分解结果 (DecomposeResult)
    participant SX as 平台模型 (StageAxisModel)
    participant Ctrl as 联动控制器 (LinkageSimulator)
    participant GX as 振镜模型 (GalvoAxisModel)
    participant Log as 记录/统计

    Ctrl->>P: 取第 i 点指令 stageX[i] + 前瞻 stageX[i+lead]
    Ctrl->>SX: Step(stageX[i+lead], dt)
    SX-->>Ctrl: 平台实测 actX（含滞后/扰动）
    Note over Ctrl: 跟随误差 e = stageX[i] − actX
    Ctrl->>P: 取高频分量 galvoX[i]
    Note over Ctrl: 振镜指令 = galvoX[i] + e（补偿开启）
    Ctrl->>GX: Step(galvoX[i] + e, dt)
    GX-->>Ctrl: 振镜偏摆 gX（视场限幅）
    Note over Ctrl: 落点 = actX + gX
    Ctrl->>Log: 记录落点、误差、更新 Max/RMS
```

## 5. 频率分解算法流程

```mermaid
flowchart TD
    Start(["DecomposeAuto(traj, FOV)"]) --> Limit["limit = FOV × margin(0.8)"]
    Limit --> High["以上限 fcHigh 分解<br/>Decompose(fcHigh)"]
    High --> CheckHigh{"maxDev &gt; limit ?"}
    CheckHigh -->|是| RetHigh["返回上限解<br/>（图形无法完全联动）"]
    CheckHigh -->|否| Low["以下限 fcLow 分解"]
    Low --> CheckLow{"maxDev ≤ limit ?"}
    CheckLow -->|是| RetLow["返回下限解<br/>（平台最省力）"]
    CheckLow -->|否| Bisect["二分搜索最低可行 fc"]
    Bisect --> Iter{"迭代 &lt;18 且<br/>区间 &gt;0.05 ?"}
    Iter -->|是| Mid["mid = (lo+hi)/2<br/>分解并算 maxDev"]
    Mid --> Judge{"maxDev ≤ limit ?"}
    Judge -->|是| Shrink["hi = mid<br/>记录 best"]
    Judge -->|否| Raise["lo = mid"]
    Shrink --> Iter
    Raise --> Iter
    Iter -->|否| RetBest["返回 best"]

    subgraph Decompose["单次 Decompose(fc) 内部"]
        D1["filtfilt 零相位低通<br/>stage = LowPass(X,Y)"]
        D2["galvo = raw − stage"]
        D3["计算 maxDev / 平台 v,a"]
        D1 --> D2 --> D3
    end

    style Start fill:#2A3A5C,stroke:#4C8DFF,color:#fff
    style RetHigh fill:#5C1F1F,stroke:#FF3B30,color:#fff
    style RetLow fill:#1F5C36,stroke:#2ECC71,color:#fff
    style RetBest fill:#1F5C36,stroke:#2ECC71,color:#fff
```

## 8. 钻孔路径规划流程（振镜优先 + 双策略）

PCB 钻孔与折线加工并列。`DrillPlanner.Plan` 根据 `DrillingStrategy` 选择孔位访问顺序，均采用振镜优先聚类 + 分区内 2-opt TSP：

```mermaid
flowchart TD
    Start(["DrillPlanner.Plan(pattern, strategy)"]) --> Strat{"strategy ?"}
    Strat -->|QualityOptimal| Grp["按孔径升序分组<br/>（量化 0.001mm）"]
    Strat -->|TimeOptimal| GF["OrderHoles（全部孔一起）"]
    Grp -->|每组分别| GF
    GF --> Dens{"密度 ≥ 4 且 galvoFirst ?"}
    Dens -->|否| Fallback["回退：Z-order / 网格最近邻"]
    Dens -->|是| Cluster["2·FOV 网格聚类→簇"]
    Cluster --> Morton["簇质心莫顿码（Z-order）排序"]
    Morton --> NN["簇内最近邻贪心初始路径"]
    NN --> Opt{"簇孔数 ≤ 300 ?"}
    Opt -->|是| TwoOpt["2-opt 局部优化"]
    Opt -->|否| Keep["保留最近邻结果"]
    TwoOpt --> Concat["拼接成最终序列"]
    Keep --> Concat
    Fallback --> Concat
    Concat --> Sample["SampleDrillingTrajectory<br/>孔间快移（激光关）+ 停留（激光开）"]

    style Start fill:#2A3A5C,stroke:#4C8DFF,color:#fff
    style TwoOpt fill:#1F5C36,stroke:#2ECC71,color:#fff
    style Fallback fill:#4A3A1B,stroke:#E6A02E,color:#fff
```

> **双模式加工**（`DecomposeBoth`）：折线轮廓与钻孔孔位采样后**拼接为单条轨迹**（先加工轮廓再环切圆孔）；其中 `FromCircle` 标记的圆轮廓从折线链路排除，避免圆被加工两次。
