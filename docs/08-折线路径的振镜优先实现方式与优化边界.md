# 08 - 折线路径的振镜优先实现方式与优化边界

> 评估对象：`PathSampler.Sample`（等时采样）+ `FrequencyDecomposer.Decompose`（频域分解）链路，
> 核心问题：**折线路径（LWPOLYLINE/LINE/ARC 展开后的轮廓）是否也需要振镜优先？与钻孔模式的振镜优先有何异同？**
>
> 本文对照 07 号文档（钻孔振镜优先策略），梳理折线路径在连续域下振镜优先的等价实现、当前行为、
> 以及"多条离散折线"段间空程的潜在优化方向。

---

## 一、结论先行

| 路径类型 | 数据形态 | 振镜优先实现方式 | 当前状态 |
|---|---|---|---|
| **钻孔路径** | 离散孔位（可重排） | 空间聚类（`PlanGalvoFirst`） | ✅ 已实现（07 号文档） |
| **连续折线** | 时间参数化轨迹（不可重排） | **频域分解**（`FrequencyDecomposer`） | ✅ 已天然实现 |
| **多条离散折线** | 多段轮廓 + 段间空程 | 段间 TSP 排序 | ⚠️ 尚未优化 |

**总体判断**：
- **连续折线**：频域分解 = 振镜优先的"连续形态"，**无需额外改造**
- **多条离散折线**（大量小轮廓场景）：段间 Rapid 空程有优化空间，可引入类似 `DrillPlanner` 的 TSP 排序

---

## 二、连续折线：频域分解 = 振镜优先的连续形态

### 1. 当前链路

```
Polylines（多条轮廓）
  │  PathSampler.Sample（等时采样 → 时间参数化轨迹）
  ▼
SampledTrajectory（X[], Y[], 含 Rapid 段，dt = 1/SampleRate）
  │  FrequencyDecomposer.Decompose（Butterworth 零相位低通）
  ▼
DecomposeResult
  ├─ StageX/Y  = 低频分量（平台指令，宏观轮廓）
  └─ GalvoX/Y  = 高频残差（振镜指令 = 原始 − 平台）
```

### 2. 频域分解的物理含义

对轨迹 `x(t)` 做零相位二阶 Butterworth 低通滤波，截止频率 `fc`：

```
x(t) = x_stage(t) + x_galvo(t)
       └── 低频 (< fc)    └── 高频 (> fc)
       └── 平台承载        └── 振镜承载
```

- **平台走低频大行程**：宏观轮廓（直线段、大圆弧）
- **振镜走高频小行程**：微观细节（尖角、小圆弧、锯齿）
- **截止频率自动搜索**（`DecomposeAuto`）：二分查找使振镜偏摆 ≤ FOV 的最低 `fc`，从而最小化平台速度/加速度需求

### 3. 与钻孔模式的对照

| 维度 | 钻孔（离散） | 折线（连续） |
|---|---|---|
| 决策变量 | 孔的访问顺序 | 轨迹的频率分割 |
| 优化方法 | 空间聚类 + 莫顿序 | 频域低通滤波 |
| 振镜承载 | 簇内短跳转 | 高频细节（尖角/小弧） |
| 平台承载 | 簇间长跳转 | 低频宏观（整体轮廓） |
| 优化目标 | 最小化平台跳跃次数 | 最小化平台速度/加速度 |
| 实现位置 | `DrillPlanner.PlanGalvoFirst` | `FrequencyDecomposer.DecomposeAuto` |

**关键洞察**：两者本质是**同一思想在不同域的体现**——
- 钻孔：**空间域**聚类，按"距离"划分振镜/平台职责
- 折线：**频率域**滤波，按"频率"划分振镜/平台职责

## 三、多条离散折线：段间空程的优化空间

### 1. 当前行为

- `Polylines` 按 DXF 解析顺序依次加工
- 段间通过 `Rapid`（快速移动，激光关）连接
- Rapid 也被采样进轨迹，过 `FrequencyDecomposer` 分解

### 2. 问题

段间 Rapid 是"纯空程"（不加工），但被采样后会产生低频分量：

```
contour_1 终点 ─── Rapid ───> contour_2 起点
                ↑
                这段被采样后产生低频分量
                平台必须跟踪 → 频繁长距离跳跃
```

类似于钻孔模式改造前的 Z-order 逐孔移动——**平台在每两个轮廓之间都移动**。

### 3. 可优化方向：段间 TSP 排序

对多条轮廓做**段间最近邻排序**（类似 `DrillPlanner.OrderByNearestGrid`，但需考虑轮廓的起点/终点/方向）：

```
当前：contour_1 → rapid → contour_2 → rapid → contour_3 → ...
优化：按最近邻重排 → contour_3 → rapid → contour_1 → rapid → contour_2 → ...
```

**与钻孔排序的复杂度对比**：

| 维度 | 钻孔排序 | 轮廓排序 |
|---|---|---|
| 单元 | 单点（孔） | 有向线段（起点→终点） |
| 距离 | 点对点对称 | 终点→下一起点（**非对称 TSP**） |
| 约束 | 无 | 嵌套关系 / 先内后外 / 方向 |
| 难度 | O(n log n) 莫顿码 | O(n²) 最近邻 / 2-opt |

### 4. 实际收益评估

| 场景 | 当前频域分解是否够用 | 段间排序收益 |
|---|---|---|
| 单条长轮廓（如螺旋线） | ✅ 完全够用 | 不适用 |
| 少量大轮廓（如 10 个矩形） | ✅ Rapid 占比小 | 🟠 微小 |
| **大量小轮廓（如 10k 个焊盘/标记）** | ⚠️ Rapid 占比大 | ✅ **显著**（类似钻孔场景） |
| 嵌套轮廓（如 PCB 铜皮岛） | ⚠️ 顺序影响质量 | 🟠 需配合工艺约束 |

**判断标准**：
```
Rapid 总长 / (Rapid 总长 + 加工总长) > 30%  →  值得引入段间排序
```

## 四、代码改动建议（可选）

### 1. 增加 Rapid 占比统计

在 `Decompose` 末尾追加：

```csharp
double rapidLen = 0, cutLen = 0;
for (int i = 1; i < traj.Count; i++)
{
    double dx = traj.X[i] - traj.X[i - 1];
    double dy = traj.Y[i] - traj.Y[i - 1];
    double d = Math.Sqrt(dx * dx + dy * dy);
    if (traj.Rapid[i]) rapidLen += d; else cutLen += d;
}
double rapidRatio = rapidLen / Math.Max(rapidLen + cutLen, 1e-9);
PlanInfo += $"Rapid 占比：{rapidRatio:P0}  (加工 {cutLen:F0}mm / 空程 {rapidLen:F0}mm)\n";
```

### 3. 段间 TSP 排序的核心算法（草案）

```csharp
// 轮廓级最近邻排序（非对称 TSP，贪心）
public static List<PathPolyline> OrderContours(List<PathPolyline> contours)
{
    int n = contours.Count;
    if (n <= 1) return contours;
    
    // 提取每条轮廓的起点/终点
    var starts = contours.Select(c => c.Points[0]).ToArray();
    var ends = contours.Select(c => c.Points[^1]).ToArray();
    
    var used = new bool[n];
    var ordered = new List<PathPolyline>(n);
    double px = 0, py = 0;  // 从原点出发
    
    for (int step = 0; step < n; step++)
    {
        int best = -1;
        double bestD2 = double.MaxValue;
        for (int i = 0; i < n; i++)
        {
            if (used[i]) continue;
            // 考虑方向：正向 vs 反向
            double dFwd = Dist2(px, py, starts[i].X, starts[i].Y);
            double dRev = Dist2(px, py, ends[i].X, ends[i].Y);
            double d = Math.Min(dFwd, dRev);
            if (d < bestD2) { bestD2 = d; best = i; }
        }
        used[best] = true;
        // 选择更近的方向
        double fwdD = Dist2(px, py, starts[best].X, starts[best].Y);
        double revD = Dist2(px, py, ends[best].X, ends[best].Y);
        if (revD < fwdD) contours[best].Reverse();  // 反向
        ordered.Add(contours[best]);
        var ep = ordered[^1].Points[^1];
        px = ep.X; py = ep.Y;
    }
    return ordered;
}
```

## 六、结论

**折线路径的振镜优先**：
- **连续折线**：频域分解已天然实现，**无需额外改造**
- **多条离散折线**：段间 Rapid 空程有优化空间，**仅在大量小轮廓场景（Rapid 占比 > 30%）值得引入 TSP 排序**

**与钻孔模式的本质联系**：
- 钻孔 = **空间域**聚类（按距离划分振镜/平台职责）
- 折线 = **频率域**滤波（按频率划分振镜/平台职责）
- 段间排序 = 折线模式的"空间域补充"（减少段间 Rapid 的低频分量）

**建议**：先加 Rapid 占比统计（§四.1），让用户看到当前数据，再决定是否值得实现段间 TSP 排序。
