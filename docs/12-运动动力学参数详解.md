# 12 - 运动动力学参数详解

## 一、概述

频率分解界面现在包含**完整的运动动力学参数配置**，这些参数直接影响：
- ✅ 加工精度（尖角保真度、轨迹跟随性）
- ✅ 加工效率（空程时间、加速度响应）
- ✅ 加工质量（过切/欠切、表面粗糙度）

---

## 二、参数分类

### 2.1 基本参数（原有）

| 参数 | 符号 | 默认值 | 范围 | 单位 | 说明 |
|------|------|--------|------|------|------|
| **进给速度** | FeedSpeed | 80 | 10-400 | mm/s | 激光出光时的加工速度 |
| **采样频率** | SampleRate | 1000 | 500-4000 | Hz | 控制/采样频率，决定轨迹离散化密度 |
| **振镜半视场** | GalvoFov | 5.0 | 1-25 | mm | 振镜扫描范围（±FOV） |
| **截止频率** | CutoffHz | 6.0 | 0.5-40 | Hz | Butterworth 滤波器截止频率 |

### 2.2 运动动力学参数（新增）

| 参数 | 符号 | 默认值 | 范围 | 单位 | 重要性 |
|------|------|--------|------|------|--------|
| **平台空移速度** | JumpSpeedPlatform | 500 | 100-1000 | mm/s | ⭐⭐⭐ |
| **振镜空移速度** | JumpSpeedGalvo | 2000 | 500-5000 | mm/s | ⭐⭐⭐ |
| **平台加速度** | AccelPlatform | 1000 | 100-3000 | mm/s² | ⭐⭐⭐⭐⭐ |
| **振镜加速度** | AccelGalvo | 5000 | 1000-10000 | mm/s² | ⭐⭐⭐⭐ |

| **平台减速度** | DecelPlatform | 1000 | 100-3000 | mm/s² | ⭐⭐⭐ |

## 三、参数详解

### 3.1 平台空移速度（JumpSpeedPlatform）

**物理意义**：
- 平台在**激光关闭**状态下的快速移动速度
- 用于非加工区域（如孔间移动、轮廓跳转）

**默认值**：500 mm/s

**调整建议**：
- **高值（800-1000）**：减少空程时间，提高效率
  - 适用场景：大批量生产、简单几何
  - 风险：振动增大、定位精度下降
- **低值（200-400）**：平稳移动，提高定位精度
  - 适用场景：精密加工、复杂几何
  - 风险：空程时间增加

**计算公式**：
```
空程时间 = 移动距离 / JumpSpeedPlatform
```

**示例**：
- 孔间距 50mm，JumpSpeed=500mm/s → 空程时间 = 0.1s
- 孔间距 50mm，JumpSpeed=200mm/s → 空程时间 = 0.25s

---

### 3.2 振镜空移速度（JumpSpeedGalvo）

**物理意义**：
- 振镜在**激光关闭**状态下的扫描速度
- 用于 FOV 内的快速定位

**默认值**：2000 mm/s

**调整建议**：
- **高值（3000-5000）**：极快响应，适合微孔加工
  - 适用场景：PCB 微孔（<1mm）、高密度孔阵
  - 风险：振镜电机过热、轨迹过冲
- **低值（1000-2000）**：稳定扫描，适合大孔加工
  - 适用场景：大孔环切（>3mm）、厚板加工
  - 风险：加工时间增加

**与 FOV 的关系**：
```
最大扫描时间 = 2 × FOV / JumpSpeedGalvo
```

**示例**：
- FOV=5mm，JumpSpeed=2000mm/s → 扫描时间 = 5ms
- FOV=10mm，JumpSpeed=2000mm/s → 扫描时间 = 10ms

---

### 3.3 平台加速度（AccelPlatform）⭐⭐⭐⭐⭐

**物理意义**：
- 平台伺服电机的加速能力
- 决定速度达到设定值的时间

**默认值**：1000 mm/s²

**调整建议**：
- **高值（2000-3000）**：快速响应，适合高速加工
  - 适用场景：短距离移动、频繁变速
  - 风险：机械振动、电机过载
- **低值（500-1000）**：平稳加速，适合精密加工
  - 适用场景：长距离连续加工
  - 风险：加速段过长，效率下降

**加速时间计算**：
```
加速时间 = 目标速度 / AccelPlatform
加速距离 = 0.5 × AccelPlatform × 时间²
```

**示例**：
- 目标速度 100mm/s，Accel=1000mm/s² → 加速时间 = 0.1s，加速距离 = 5mm
- 目标速度 100mm/s，Accel=500mm/s² → 加速时间 = 0.2s，加速距离 = 10mm

**对尖角的影响**：
- 加速度不足 → 尖角处速度未达设定值 → 尖角变圆角
- 加速度过高 → 过冲 → 尖角过切

---

### 3.4 振镜加速度（AccelGalvo）

**物理意义**：
- 振镜电机的加速能力
- 决定扫描速度响应

**默认值**：5000 mm/s²

**调整建议**：
- **高值（8000-10000）**：极快响应，适合高频扫描
  - 适用场景：微孔加工、快速跳孔
  - 风险：振镜电机过热、轨迹失真
- **低值（2000-5000）**：稳定扫描，适合大孔环切
  - 适用场景：大孔加工、厚板切割
  - 风险：扫描时间增加

**与平台加速度的配合**：
```
总加速度响应 = 1 / (1/AccelPlatform + 1/AccelGalvo)
```

**示例**：
- AccelPlatform=1000, AccelGalvo=5000 → 总响应 ≈ 833 mm/s²
- AccelPlatform=500, AccelGalvo=2000 → 总响应 ≈ 400 mm/s²

---

### 3.5 拐角系数（CornerFactor）⭐⭐⭐⭐

**物理意义**：
- 控制尖角处的速度衰减策略
- 0.0 = 完全尖角（速度降至 0）
- 1.0 = 完全圆滑（速度不衰减）

**默认值**：0.5（折中策略）

**调整建议**：
- **低值（0.0-0.3）**：尖角保真度高
  - 适用场景：方孔、锐角轮廓
  - 风险：尖角处过烧（停留时间长）
- **高值（0.7-1.0）**：圆滑过渡，效率高
  - 适用场景：圆孔、连续曲线
  - 风险：尖角变圆角，精度下降

**速度衰减公式**：
```
拐角速度 = 进给速度 × (1 - CornerFactor)
```

**示例**：
- 进给速度 100mm/s，CornerFactor=0.5 → 拐角速度 = 50mm/s
- 进给速度 100mm/s，CornerFactor=0.0 → 拐角速度 = 0mm/s（完全停止）
- 进给速度 100mm/s，CornerFactor=1.0 → 拐角速度 = 100mm/s（不减速）

**对加工质量的影响**：
| CornerFactor | 尖角保真度 | 加工效率 | 过烧风险 | 适用场景 |
|-------------|-----------|---------|---------|---------|
| 0.0 | ⭐⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐⭐ | 方孔、锐角 |
| 0.3 | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ | 精密零件 |
| 0.5 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | 通用加工 |
| 0.7 | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ | 大批量生产 |
| 1.0 | ⭐ | ⭐⭐⭐⭐⭐ | ⭐ | 圆孔/曲线 |

---

### 3.6 平台减速度（DecelPlatform）

**物理意义**：
- 平台停止时的减速度
- 影响定位精度和停止时间

**默认值**：1000 mm/s²（通常与加速度相同）

**调整建议**：
- **与加速度保持一致**：对称的加减速曲线
- **略低于加速度**：更平稳的停止，减少冲击

**减速距离计算**：
```
减速距离 = 0.5 × 初速度² / DecelPlatform
```

**示例**：
- 初速度 100mm/s，Decel=1000mm/s² → 减速距离 = 5mm
- 初速度 100mm/s，Decel=500mm/s² → 减速距离 = 10mm

## 四、参数配合策略

### 4.1 精密加工模式

**适用场景**：精密零件、微孔加工、尖角轮廓

**参数配置**：
```
JumpSpeedPlatform = 300 mm/s    (低空移速度)
JumpSpeedGalvo = 1500 mm/s      (低扫描速度)
AccelPlatform = 800 mm/s²       (低加速度)
AccelGalvo = 3000 mm/s²         (低加速度)
CornerFactor = 0.2              (尖角保真)
DecelPlatform = 800 mm/s²       (平稳停止)
```

**特点**：
- ✅ 高精度（尖角保真度⭐⭐⭐⭐⭐）
- ✅ 低振动
- ❌ 加工时间长

---

### 4.2 高效生产模式

**适用场景**：大批量生产、简单几何、通孔加工

**参数配置**：
```
JumpSpeedPlatform = 800 mm/s    (高空移速度)
JumpSpeedGalvo = 4000 mm/s      (高扫描速度)
AccelPlatform = 2000 mm/s²      (高加速度)
AccelGalvo = 8000 mm/s²         (高加速度)
CornerFactor = 0.8              (圆滑过渡)
DecelPlatform = 2000 mm/s²      (快速停止)
```

**特点**：
- ✅ 高效率（空程时间减少 60%）
- ✅ 快速响应
- ❌ 尖角保真度低

---

### 4.3 通用加工模式（默认）

**适用场景**：通用零件、混合特征

**参数配置**：
```
JumpSpeedPlatform = 500 mm/s    (中等空移速度)
JumpSpeedGalvo = 2000 mm/s      (中等扫描速度)
AccelPlatform = 1000 mm/s²      (中等加速度)
AccelGalvo = 5000 mm/s²         (中等加速度)
CornerFactor = 0.5              (折中策略)
DecelPlatform = 1000 mm/s²      (平稳停止)
```

**特点**：
- ✅ 平衡精度与效率
- ✅ 适应多种场景
- ⭐ 推荐默认配置

## 六、常见问题与解决方案

### Q1：尖角变圆角，精度下降

**原因**：
- 加速度不足
- 拐角系数过高
- 进给速度过快

**解决方案**：
1. 提高加速度（AccelPlatform → 1500-2000）
2. 降低拐角系数（CornerFactor → 0.2-0.3）
3. 降低进给速度（FeedSpeed → 50-80）

---

### Q2：加工时间过长，效率低

**原因**：
- 空移速度过低
- 加速度过低
- 拐角系数过低

**解决方案**：
1. 提高空移速度（JumpSpeedPlatform → 800）
2. 提高加速度（AccelPlatform → 2000）
3. 提高拐角系数（CornerFactor → 0.7-0.8）

---

### Q3：尖角处过烧

**原因**：
- 拐角系数过低（速度降至 0）
- 持留时间过长

**解决方案**：
1. 提高拐角系数（CornerFactor → 0.3-0.5）
2. 减少持留时间（HoldTime → 10-20ms）
3. 启用功率渐变功能

---

### Q4：振镜轨迹过冲

**原因**：
- 振镜加速度过高
- JumpSpeedGalvo 过高

**解决方案**：
1. 降低振镜加速度（AccelGalvo → 3000-4000）
2. 降低空移速度（JumpSpeedGalvo → 1500-2000）
3. 增加阻尼系数
